# 生图模型配置

应用内置 10 个生图 provider，全部在 **设置 → API Keys** 标签页填入对应 Key 后即可使用。Key 仅保存在本地 `settings.json`，不会上传。

> 推荐新手先用 **硅基流动 SiliconFlow**：注册即送额度，OpenAI 兼容，支持 Kolors（可图）与 FLUX 系列，且支持图生图。

## 各家 Key 说明

### 硅基流动 SiliconFlow（推荐）
1. 注册 https://cloud.siliconflow.cn/
2. 进入 **账户 → API 密钥** 创建一个 `sk-` 开头的 Key。
3. 填入设置 API Keys 的「硅基流动」字段。
4. 模型选 `Kolors (可图)` 即可文生图 / 图生图。

### OpenAI（gpt-image-1 / DALL·E 3）
- 在 https://platform.openai.com/api-keys 创建 Key（需账号有图像权限/已绑定支付）。
- gpt-image-1 支持图生图与图片编辑，效果优于 DALL·E 3。
- 如需走代理/自建网关，可在设置中填写自定义 Base URL。

### Google Imagen
- 在 https://aistudio.google.com/app/apikey 获取 Gemini API Key。

### 阿里 通义万相（DashScope）
- 开通 DashScope，获取 API-KEY（`sk-` 开头）填入 `dashscope` 字段。

### 字节 即梦 Seedream（火山引擎 Ark）
- 在火山引擎开通豆包/即梦图像服务，使用 Ark API Key。

### 百度 文心一格
- 在百度智能云千帆获取访问凭证。

### 智谱 CogView
- 在 https://open.bigmodel.cn/ 获取 API Key。

### 腾讯 混元生图
- 在腾讯云开通混元生图，使用对应密钥。

### MiniMax 海螺
- 在 https://platform.minimaxi.com/ 获取 API Key。

## 自定义 Base URL
对支持 OpenAI 兼容协议的 provider（如 OpenAI、硅基流动），可在设置中填写自定义 Base URL 以走代理或私有网关。

## 常见问题
- **生成的是带 DEMO 水印的占位图？** 说明该 provider 未配置有效 Key，应用回退到 DEMO 模式。请在 API Keys 中填入正确 Key。
- **401 / 鉴权失败？** 检查 Key 是否复制完整、是否过期、账户是否有余额/权限。
- **尺寸报错？** 不同模型支持的尺寸不同，请使用模型下拉中列出的尺寸。
