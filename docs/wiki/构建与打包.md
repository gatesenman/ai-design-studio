# 构建与打包

## 技术栈
Electron 33 · React 18 · TypeScript 5 · Vite 5 · Fabric.js 6 · Zustand 5 · Tailwind CSS 3 · electron-builder 25

## 环境要求
- Node.js ≥ 20（推荐 22.x）
- npm ≥ 10

## 获取源码
```bash
git clone https://github.com/gaosichun888/ai-design-studio.git
cd ai-design-studio
npm install
```

## 开发模式
```bash
npm run electron:dev
```
该命令并行启动 Vite 开发服务器并在其就绪后拉起 Electron（`NODE_ENV=development`）。

## 代码检查
```bash
npm run lint        # ESLint，0 warning 通过
npm run typecheck   # tsc 类型检查（app + electron 两套 tsconfig）
```

## 仅构建 Web/渲染资源
```bash
npm run build:web   # tsc -b && vite build -> dist/ + dist-electron/
```

## 打包安装包
`npm run build` 默认会构建当前平台。也可按平台分别打包：

```bash
# Linux AppImage
npx electron-builder --linux AppImage --x64

# Windows NSIS 安装包（在 Linux 上需安装 wine + wine32）
npx electron-builder --win nsis --x64

# macOS dmg（需在 macOS 上执行）
npx electron-builder --mac dmg
```

产物输出到 `release/`：
- `AI Design Studio Setup 1.0.0.exe`（Windows）
- `AI Design Studio-1.0.0.AppImage`（Linux）
- `AI Design Studio-1.0.0.dmg`（macOS，需在 mac 上打）

### 在 Linux 上交叉编译 Windows .exe
electron-builder 通过 wine 在 Linux 上生成 Windows 安装包，需要 64 位与 32 位 wine：
```bash
sudo dpkg --add-architecture i386
sudo apt-get update
sudo apt-get install -y wine64 wine32:i386
npx electron-builder --win nsis --x64
```
> 安装包未做代码签名（无证书）。如需签名，在 electron-builder 配置中提供证书信息。

## 目录结构
```
ai-design-studio/
├─ electron/            # 主进程 + 预加载 + 各 provider 生图服务
│  └─ services/providers/
├─ shared/              # 跨进程共享：providers.ts / builtinSkills.ts / types.ts
├─ src/                 # React 渲染层
│  ├─ components/Canvas # 画布、工具栏、右键菜单
│  ├─ components/Chat   # 聊天面板、Composer
│  ├─ components/Settings
│  └─ stores/           # Zustand 状态
├─ package.json         # 含 electron-builder 配置（build 字段）
└─ ...
```

## 关键配置说明
- `electron/main.ts` 中 `webPreferences.sandbox = false`：ESM 预加载脚本需在非沙箱渲染进程加载，否则 IPC 与设置持久化失效。
- 设置文件位置：`~/.config/ai-design-studio/settings.json`（Windows: `%APPDATA%/ai-design-studio/settings.json`）。
