# 功能总览

## 1. 布局
- 左侧：聊天窗口（对话生成、批量、长图分节、MCoT 思考步骤展示）
- 右侧：无限自由画布（Fabric.js）
- 可拖拽分隔条调整两栏宽度

## 2. 生图能力
| 能力 | 说明 |
|------|------|
| 文生图 | 文本提示词生成图片 |
| 图生图 | 以一张参考图 + 提示词生成（画布右键「用 AI 改这张图」一键进入） |
| 批量生成 | 一次生成 1–N 张，并行调用，结果自动排布到画布 |
| 多尺寸 | 1024×1024 / 1024×1536 / 1536×1024 等 |

## 3. 生图模型（10 个 provider）
国外：OpenAI（gpt-image-1 / DALL·E 3）、Google Imagen
国内：阿里通义万相、字节即梦 Seedream（豆包/火山）、百度文心一格、智谱 CogView、腾讯混元、MiniMax 海螺、硅基流动（聚合 Kolors / FLUX 等）

详见 [生图模型配置](生图模型配置)。

## 4. 自由画布
- 选择、移动、缩放、旋转、删除
- 撤销 / 重做（最多 50 步历史）
- 复制 / 粘贴 / 剪切 / 创建副本 / 全选
- 多选对齐（左/中/右/上/中/下）与分布（水平/垂直均匀）
- 拖拽对齐吸附（对象边缘/中心）+ 实时辅助线
- 点阵网格背景（可开关）
- 空格 + 拖拽平移、滚轮缩放、缩放到选区/适配内容
- 右键上下文菜单
- 本地图片拖入画布（mood board）

详见 [画布操作与快捷键](画布操作与快捷键)。

## 5. 长图分节生成
为电商详情页等「多张图竖向拼接」场景设计：分节生成并保证各节风格连贯，再框选拼接导出为一张长图。详见 [长图分节生成](长图分节生成)。

## 6. Skill 工作流
内置 10 个 Skill：电商主图、电商海报、电商详情页（长图）、品牌全案（长图）、社媒成套（长图）、价目表、菜单、产品目录（长图）、宣传册（长图）、IP 形象。支持自定义。详见 [Skill 工作流](Skill工作流)。

## 7. 系统设置（7 标签页）
通用（默认模型/尺寸/数量、主题）、画布（网格/吸附/背景色）、导出（格式 PNG/JPEG、质量、倍数 1x/2x/4x、长图间距）、API Keys、品牌套件、快捷键、关于。所有偏好持久化到本地并实时同步画布。

## 8. 导出
- 单图导出（PNG / JPEG，1x/2x/4x）
- 框选多图拼接导出为长图（可设拼接间距）
