# 画布操作与快捷键

右侧为基于 Fabric.js 的无限自由画布，支持完整的设计排版操作。

## 基本操作
- **选择 / 移动**：单击选中，拖拽移动。
- **缩放对象**：拖拽选中对象的控制点；按角点等比缩放。
- **旋转**：拖拽对象上方旋转手柄。
- **多选**：框选，或按住 Shift 逐个点选。
- **画布平移**：按住 **空格 + 拖拽**，或拖动滚动条。
- **画布缩放**：滚轮缩放（以光标为中心）。

## 对齐与分布（多选时）
工具栏提供对齐与分布按钮：
- 对齐：左 / 水平居中 / 右 / 上 / 垂直居中 / 下
- 分布：水平均匀、垂直均匀

## 拖拽对齐吸附
移动对象时自动检测与其他对象的 **边缘 / 中心** 对齐，并显示紫色辅助线，松手即吸附。可在 **设置 → 画布** 中开关。

## 撤销 / 重做
基于画布快照的历史栈（最多 50 步），支持撤销与重做画布上的增删改与移动。

## 右键上下文菜单
在对象上右键可：复制 / 粘贴 / 创建副本 / 删除 / 上移一层 / 下移一层；多选时显示对齐按钮；单张图片时显示 **「用 AI 改这张图」**（一键进入图生图）。

## 网格与背景
- 点阵网格背景可在 **设置 → 画布** 开关。
- 画布背景色可自定义。

## 导入本地图片
直接把本地图片文件拖入画布即可作为参考图 / mood board 素材。

## 键盘快捷键（共 14 项）

| 快捷键 | 功能 |
|--------|------|
| Ctrl + Z | 撤销 |
| Ctrl + Shift + Z / Ctrl + Y | 重做 |
| Ctrl + C / V / X | 复制 / 粘贴 / 剪切 |
| Ctrl + D | 创建副本 |
| Ctrl + A | 全选 |
| Delete / Backspace | 删除选中 |
| 方向键 | 微移 1px（按住 Shift 为 10px） |
| [ / ] | 下移 / 上移一层 |
| Ctrl + 0 | 重置缩放为 100% |
| Ctrl + 1 | 适应内容 |
| Ctrl + = / Ctrl + - | 放大 / 缩小 |
| F | 缩放到选区 |
| 空格 + 拖拽 | 平移画布 |
| Esc | 取消选择 / 关闭菜单 |

> 编辑文字时上述快捷键自动禁用，避免误触。
