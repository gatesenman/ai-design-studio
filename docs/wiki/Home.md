# AI Design Studio Wiki

> 类似 [lovart.ai](https://www.lovart.ai) 的 **AI 驱动设计桌面程序**：左侧聊天、右侧自由画布，面向电商/海报/详情页等设计场景。

跨端桌面应用（Windows / macOS / Linux），基于 **Electron + React + TypeScript + Fabric.js + Zustand**。

## 一句话特性

- 文生图 / 图生图 / 批量生成（并行）
- 10 家生图模型可插拔切换：OpenAI gpt-image-1 / DALL·E 3、Google Imagen、阿里通义万相、字节即梦 Seedream、百度文心一格、智谱 CogView、腾讯混元、MiniMax、硅基流动
- 无限自由画布：拖拽、缩放、对齐吸附、辅助线、撤销/重做、右键菜单
- 长图分节连贯生成（电商详情页场景）+ 框选拼接导出
- Skill 工作流：内置电商主图/海报/详情页 + 品牌全案/社媒成套/价目表/菜单/产品目录/宣传册/IP 形象
- 系统级设置（7 标签页）+ 品牌套件 + 偏好持久化

## 截图
