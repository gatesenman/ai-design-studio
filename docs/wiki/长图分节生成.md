# 长图分节生成

## 为什么需要
电商详情页、活动落地页等长图，通常是 **多张图竖向拼接** 而成。若各节单独生成，风格（配色、光影、字体气质）容易不一致。本功能把一张长图拆成多个「节」分别生成，并通过统一的风格描述/种子保证 **各节连贯**，最后框选拼接导出为一张长图。

## 使用步骤
1. 在聊天框选择带「长图」标记的 Skill（如 **电商详情页**、**产品目录**、**宣传册**、**品牌全案**、**社媒成套**），或直接描述要分几节。
2. 填写整体风格（如「深空灰 + 电光蓝、极简科技风」）与各节内容（如：主图 / 卖点 / 参数 / 场景 / 售后）。
3. 选择 provider 与模型（推荐硅基流动 Kolors）。
4. 生成后各节图片按顺序排布到画布。
5. 在画布上从上到下框选所有节。
6. 点击工具栏 **导出**，得到一张竖向拼接的长图。

## 拼接间距
在 **设置 → 导出 → 长图间距** 可设置节与节之间的拼接间隙（像素）。设为 0 即无缝拼接。

## 保证连贯的技巧
- 在风格描述中固定 **配色 + 背景 + 光影 + 版式**，并在每节复用同一段风格前缀。
- 同一批使用同一 provider/模型。
- 控制每节尺寸一致（如统一 1024×768 或 720×1280）。
- 需要更强一致性时，可对后续节使用 **图生图**，以上一节为参考。

## 导出规格
- 格式：PNG / JPEG（设置可选）
- 倍数：1x / 2x / 4x
- 输出为单张长图，宽度取各节宽度，高度为各节之和（含间距）。
