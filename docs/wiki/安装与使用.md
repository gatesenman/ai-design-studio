# 安装与使用

## 下载安装包

前往 [Releases](https://github.com/gaosichun888/ai-design-studio/releases) 页面，下载对应平台的安装包：

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows | `AI Design Studio Setup 1.0.0.exe` | NSIS 安装程序，双击安装 |
| Linux | `AI Design Studio-1.0.0.AppImage` | 赋予可执行权限后直接运行 |
| macOS | （从源码构建 dmg，见 [构建与打包](构建与打包)） | 需在 macOS 上打包 |

### Windows
双击 `AI Design Studio Setup 1.0.0.exe` 完成安装，桌面/开始菜单会出现 AI Design Studio。
> 安装包未做代码签名，Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可。

### Linux
```bash
chmod +x "AI Design Studio-1.0.0.AppImage"
./"AI Design Studio-1.0.0.AppImage"
# 若沙箱报错可加: --no-sandbox
```

## 首次配置

1. 打开应用，点击右上角 **设置（齿轮）**。
2. 进入 **API Keys** 标签页，为你要用的 provider 填入 API Key（如硅基流动、OpenAI）。详见 [生图模型配置](生图模型配置)。
3. （可选）在 **通用** 标签页设置默认模型 / 尺寸 / 生成数量 / 主题。
4. Key 与偏好会保存到本地：`~/.config/ai-design-studio/settings.json`（Windows 为 `%APPDATA%/ai-design-studio/settings.json`）。

## 生成第一张图

1. 左侧聊天框输入提示词，例如：`一瓶白色护肤精华，柔光摄影，浅灰背景，电商主图`。
2. 选择 provider / 模型 / 尺寸 / 数量。
3. 回车或点击发送 → 生成的图片自动出现在右侧画布。
4. 在画布上拖动、缩放、对齐排版。
5. 选中后右键 **用 AI 改这张图** 可进入图生图继续优化。
6. 框选需要的图，点击工具栏 **导出**。

## 数据与隐私
- 所有 API Key 仅保存在本地配置文件，不上传任何服务器。
- 生图请求直接由你的本机发往对应模型厂商。
