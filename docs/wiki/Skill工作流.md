# Skill 工作流

Skill 是预设好的「场景化生成模板」：封装了提示词结构、推荐 provider/模型、尺寸、是否长图分节等，点选后填少量参数即可产出成套设计。

## 内置 Skill（10 个）

|-------|------|:----:|----------|
| 电商主图 | 单品主图，干净背景、突出产品 | | gpt-image-1 |
| 电商海报 | 促销/活动海报排版 | | gpt-image-1 |

## 使用方法
1. 在聊天面板选择一个 Skill。
2. 弹窗内填写场景参数（产品名、卖点、风格、节数等）。
3. 选择 provider / 模型（可覆盖默认值）。
4. 生成，结果排布到画布；长图类 Skill 可框选后拼接导出。

## 运行时切换模型
每个 Skill 运行弹窗内都带 provider / 模型选择器，可临时切换到任意已配置 Key 的 provider（例如把默认 gpt-image-1 的 Skill 切到硅基流动 Kolors 跑）。

## 自定义 Skill
可基于内置模板创建自定义 Skill：自定义名称、提示词结构、默认 provider/模型、尺寸与是否长图分节，保存后出现在 Skill 列表中复用。
